# react.v1.2

Early React expenses tracker practice project.

## What it does

- renders a list of expenses;
- adds new expense items through a form;
- filters expenses by year;
- displays simple chart bars for monthly totals.

## Run

```bash
cd first
npm install
npm start
```

## Build

```bash
cd first
npm run build
```

## Status

Canonical React learning repo among `react.v1`, `react.v1.1`, and `react.v1.2`.

This is a course-era React practice app, not a production finance product.
